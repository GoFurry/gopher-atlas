## JSON 契约本质上是承诺

字段名、可空性、默认值、列表为空时返回 `[]` 还是 `null`，这些看起来都是小事，但它们都会进入客户端的假设里。

## 我更关心的不是编码技巧

相比“怎么序列化更优雅”，我更在意：

- 这个字段未来是否还稳定
- 一旦弃用要怎么过渡
- 有没有地方把 `omitempty` 当成偷懒

接口契约不是格式化结果，而是协作边界。
