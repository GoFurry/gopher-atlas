## 如何推荐文章

欢迎通过 Issue 或 Pull Request 推荐高质量 Go 文章。推荐时尽量提供：

- 文章标题
- 原文链接
- 作者与来源
- 适合的分类
- 相关标签
- 推荐理由
- 你建议的评级

## 推荐条目格式

站内文章使用统一的数据结构维护。新增文章时，请补齐以下信息：

- `id`：稳定唯一标识
- `title`：原始标题
- `url`：文章链接
- `category`：一级分类
- `tags`：标签数组
- `rating`：推荐评级
- `language`：`zh` 或 `en`
- `difficulty`：难度等级
- `summary`：简短概述
- `reason`：收录理由

## 收录建议

- 尽量优先推荐“讲明白一个核心问题”的文章
- 不建议提交纯搬运、营销导向或低信息密度内容
- 对明显过时但有历史价值的文章，请补充上下文说明

## PR 指引

- 保持字段命名统一
- 标签尽量短小明确
- 避免重复提交已收录文章
- 如果新增专题，请同时补充对应的 Markdown 导读

如果你不确定一篇文章是否适合收录，也欢迎先开 Issue 讨论。
