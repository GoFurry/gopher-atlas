## 项目定位

GopherAtlas 是一个面向 Go 开发者的高质量文章精选站。它不追求“收得多”，而是追求“选得准”。

站内核心内容不是原创长文，而是对第三方 Go 文章的整理、归类、评级和导读。我们希望把高信号内容更快地送到读者面前，让搜索、筛选和专题式阅读都更顺手。

## 收录标准

- 内容准确，观点和代码示例经得起时间检验
- 解释清晰，不只是罗列 API
- 对实际工程有启发，而非纯营销或浅层搬运
- 具备长期价值，读者几年后再看仍有收获
- 官方作者、核心贡献者或资深工程师内容优先

## 评级规则

- `S+`：极强推荐，建议优先阅读
- `S`：高质量核心文章，值得认真读完
- `A+`：很值得读，适合作为专题重点延伸
- `A`：质量稳定，适合作为补充阅读
- `B+ / B`：有参考价值，但优先级较低
- `C+ / C`：可作为补充材料或背景材料

评级表达的是推荐优先级，不是绝对分数，也不等于文章“对错”判断。
