Go 的新特性通常不是“炫技式更新”，而是围绕可维护性、可读性、标准库能力和工程体验做渐进增强。真正值得长期关注的，往往是那些会进入日常项目、工具链和标准库习惯的变化。

这一专题先收录四类变化：标准库结构化日志、循环变量语义修复、迭代器方向的语言增强，以及新一代 JSON API 的实验性演进。它们都对未来几年的 Go 工程实践有直接影响。
